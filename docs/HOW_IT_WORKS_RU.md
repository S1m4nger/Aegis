# Как работает Aegis AI

Это локальный исследовательский прототип на синтетическом PaySim. Он не проводит платежи и не блокирует реальные счета.

1. Панель отправляет `step`, `type`, `amount` в Go `POST /v1/analyze`. Go проверяет обязательные поля, типы, границы и размер JSON.
2. Go вызывает внутренний Python FastAPI-сервис с timeout. Python использует обученную Logistic Regression и отдельный калибратор, проверенные по хешам. Общая функция признаков создаёт только type, log(amount+1) и циклический час симулятора. Балансы, ID, target и флаг симулятора исключены.
3. Go выполняет безопасное JSON-дерево правил, сохраняет трассировку и вычисляет эвристический score. Затем общий модуль политики определяет конфликт и объединяет сигналы.
4. Зафиксированная политика возвращает APPROVE/REVIEW/FLAG. Если модель отсутствует или недоступна, анализ возвращает503; выдуманной оценки нет.
5. В Evidence панель читает реальные отчёты. Cost Lab передаёт Go сохранённые агрегированные действия и новые гипотетические цены ошибок. Go пересчитывает стоимость без переобучения, новых решений или записи отчётов.

## Что проверено
Обучение: шаги1–400; калибровка401–470; выбор правил/политики471–550; единственная финальная оценка551–743. Код, модель и конфигурации зафиксированы до теста. `reports/final-evaluation.lock` защищает от случайного повторного запуска.

На196601 финальной операции было2148 fraud. F1: простой гибрид0.3606, конфликтный0.3583, правила0.3053, ML0.1684. Конфликтный механизм не улучшил F1 и гипотетическую стоимость по сравнению с простым гибридом, хотя его Average Precision выше. Recall около23% означает много пропусков; это существенное ограничение.

## Важное различие
Классификационная тревога и рекомендация политики имеют разные пороги. Единичная API-рекомендация не управляет общей очередью REVIEW. Ограничение числа проверок применяется только в пакетном эксперименте, отдельно для каждого шага симулятора, без использования меток при ранжировании. Поэтому даже низкий score может дать REVIEW в единичном API. Ни rule score, ни fusion score не считаются калиброванной вероятностью.

Запуск и команды: `running.md`; реальные ошибки: `reports/error_cases.csv`; методика: `evaluation-protocol.md`. Готовность локальная; публичная публикация и сдача пока не подтверждены. ChatGPT и Codex раскрыты в Credits.
